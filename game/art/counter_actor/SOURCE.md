# Counter actor

`recipient.glb` is a derivative of Kay Lousberg's CC0 Adventurers 1.0 Mage. The standing character faces local +Z. The scene wrapper scales its 2.20-unit body to roughly 1.85 world units. Floor placement uses the original foot origin.

This copy retains the body, cape, 41-joint skin, embedded palette texture, and three animation clips. The hand props and oversized hat were omitted. Idle loops, Interact acknowledges a delivery, and Cheer greets a returning visitor. The controller returns to Idle after each gesture.

Static inspection compared the retained mesh and animation accessor payloads, target channels, skin bindings and embedded texture against the source. The reduced file is 370,004 bytes. Godot import, the rendered pose and animation transitions await engine verification.
