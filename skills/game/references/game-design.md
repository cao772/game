# 体验、规则与制作范围

## 把体验落到玩家行动

先写一句体验承诺，再说明玩家反复做的关键动作。用 MDA 区分规则、玩家互动中出现的行为、最终体验；这是一种分析视角，不是乐趣保证。

为一个设计写出：目标体验；玩家当前可知信息；可做的选择；限制或代价；即时反馈；稍后可观察的结果。玩家只能看长段文本却没有行动空间时，应明确这是阅读或演出段落，别伪称玩法。

微循环、一次游玩和长期成长要相互支持。调查可以形成“发现异常—提出解释—采取行动—看到反应—修正解释”；具体动作和反馈需随内容变化，不能全变成按提示找闪光点。

## 选择与系统

有效选择并非选项越多越好。至少说明选项为何各有价值、玩家能否预判关键代价、哪一项在什么情况下值得选。避免永远最优的技能、无代价的收益和用隐藏惩罚惩戒合理尝试。

区分数字成长、操作成长、知识成长、关系成长与新内容解锁。以调查为核心的段落可让新知识打开旧空间，不必每次都提升等级。剧情回报、资源回报和关系回报应彼此补充。

设计经济时列清来源、消耗、容量、流通速度、失败成本及重玩刷取风险。公式与数值先标假设；无样本不填“平衡通过”。不要把玩家类型标签当个体诊断，也不把随机奖励当普遍的吸引力秘诀。

## 关卡与环境叙事

把关键空间画成节点和路径：进入、识别目标、观察、行动、反馈、回访。地标既帮助导航，也承载时间与人的痕迹。环境证据要能改变判断；纯装饰作为氛围交付，不虚增“可调查内容”。

提供主方向和可选探索，通过声音、光线、视线、生活痕迹引导；文字提示是可用手段，不必为了“高级设计”禁止提示。玩家迷路和玩家主动探索不同，提示是否需要取决于观察证据。

复用空间时改变行为或后果：同一街道在事件前后的人流、可用通路、商店服务与对白。不能仅换色或塞更多拾取物。大地图扩展须有体验理由，优先做小范围高密度、可回访的内容。

## 难度、反馈和可访问性

让失败说明发生了什么、如何调整，恢复时间匹配损失。允许撤回误操作、重试、跳过已看演出与检查目标。关键线索不能仅靠颜色、声音或极短文本传达；考虑字号、字幕、按键重映射和可控阅读速度。

不同能力玩家可采用不同路线和辅助选项。难度波动要有教学、应用、组合与休息。不要用固定分钟数或固定奖励频率替代真实体验。

## 范围与验证

对新增功能记录其新增场景、独特机制、资产类型、对白量和接口依赖。选择能检验核心体验的最小切片。十个独立任务不代表十个系统必须同时新增。

设计阶段可做纸面路径推演和内容审读，明确它们不是实际游玩。获得测试授权后，才制定并执行可观察实验，例如“新玩家能否找到两种调查路径并解释选择后果”；记录人数、版本、环境、观察与不确定性。没有数据时保持待验证。

## 设计决策

短记录即可：问题、采用方案、关键理由、代价、何种证据出现时重审。常规选择由 GPT 完成，不把每个数值、支线走向或场景细节升级为作者审批。
