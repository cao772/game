# KEYBOARD_PATHS｜N24 完整键盘路径（计划，不是实测）

**ALL NOT_RUN.** 所有按键、焦点、字幕、滚动、字号、窗口失焦和辅助技术表现仅为未来验收预期。

## 从启动到更正

1. 独立 Godot 工程根为本文件所在目录。原生 GUI 接受 Tab / Shift+Tab，初始无需鼠标；使用 Tab 聚焦“重新读取固定合成数据”，再到合成错误样本按钮、A/B/C `OptionButton`。
2. 聚焦 A/B/C 选择器，按原生 Godot 候选选择键切换场景。结构进入 `SOURCE_ACCEPTED` 或 `FALLBACK_SYNTHETIC` 才允许交互；`BLOCKED` 时场景与移动/更正按钮禁用，但重新载入按钮仍可达。
3. 聚焦“文字缩放”选择器，选择 100%、125%、150%。回到文字/地图/诊断区域确认内容存在且可滚动；缩放不改变地图、claim、Undo 栈或数据来源。
4. 聚焦四个方向 Button 并按 Enter/Space：每次意图只移动一格。失败方向不会穿墙，反馈以文字呈现；Tab 可继续进入“预览到 T”“预览返回 S”。
5. 聚焦“1. 核对”并激活：状态文字从“模拟观察：未核对”转为“本次已触发合成模拟核对”，显示四向可达与采样视线两个字段。再选择“2. 明确更正内存记录”，只更新 claim，不写源 JSON。
6. 聚焦“撤销最近操作”并激活：恢复最近一次有效移动或明确更正（候选 16 级），文字显示最新状态，旧核对失效；换 A/B/C 会重置内存历史。
7. 可选第二条操作路径：用 Tab 聚焦“焦点转到网格”并按 Enter/Space，网格控件取得焦点，此时 WASD 或方向键发出**非重复**移动请求；Esc 释放网格焦点。网格没有焦点时，WASD 不应改变 P；TextEdit/OptionButton 的方向键不应误发网格移动。
8. Alt+Tab 切出窗口时所有移动被阻断；切回来后必须释放 W/A/S/D/四个方向键才能接受新的移动。切回不得自动移动或显式更正，也不能抢已聚焦的其他控件。
9. 从只读文字区可以 Tab 离开，读到结构错误的 **级别/代码/路径/原因/处理建议**。所有状态同时使用文字，颜色和声音没有独有含义。

## 可见的非颜色文字

- 地图：`#`=墙，`.`=通路，`:`=预览，`S`=起点，`T`=目标，`P`=当前格；**起终点和当前坐标另写文字**，避免只凭格子定位。
- `SOURCE_ACCEPTED`=原始合成数据结构接受，不等于游戏验证。
- `FALLBACK_SYNTHETIC`=原始合成数据拒绝/缺失，使用独立内置后备，必须保留原输入诊断。
- `BLOCKED`=无可用场景，交互不可执行，必须显示恢复建议。
- `claimed`=报告主张，可能故意错误；`actual`=仅显式 Inspect 后显示的网格模拟观察。不可把模拟值说成真实安全或实测通过。

## 注意事项

N24 **不是**已经通过真实操作的无障碍功能。原生 OptionButton 键盘交互、Tab 焦点顺序、混合键盘布局、IME、屏幕阅读器、窗口失焦通知、行/列字宽、滚动位置、150% 缩放重排都必须以后执行验证。无动画是本轮明确取舍，非缺失后再退化。
